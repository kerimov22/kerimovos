# KerimovOS Scripts

Location: /opt/scripts/

Scripts:
- hello.sh        — Greeting script
- copy-ntfs.sh    — Copy between FAT32 and NTFS
- download.sh     — Download file using curl
- backup.sh       — Backup directory
- kpt-update.sh   — Update all packages
- disks.sh        — List disks
- mount-usb.sh    — Mount USB drive

Usage:
    ksh /opt/scripts/hello.sh
    /opt/scripts/hello.sh  (direct execution)

All scripts use #!/bin/ksh shebang.
